Workflow mockup — not the app. Clickable throughout. Open Refine view to pick a list, search, choose columns and clear filters; tick rows for a bulk action; drag a column edge; sort and filter in the header. Nothing here is Angular yet.

Accounts

These belong to no list. Removing an account from a list keeps the account — a list is a selection, not an owner. They stay here, and a re-import of the same company will match them rather than creating a duplicate. This screen is the only place they appear.
⌕

What to check

  • Columns are a dropdown. One line whether there are six choices or twenty, with All / Essentials so a wrecked layout is one click from usable.
  • Refine view is one row and collapses. List, search, columns, filter-clearing and export — expand, apply, close, and the table has the height back.
  • The collapsed bar still names the list. Scope moved inside the panel, so it leads the summary — you can always see which accounts you are looking at without opening anything.
  • Selection is leftmost. The header box selects what you can see: filter to 6 of 10, tick the header, and you have 6 — not a silent 10.
  • The action bar only appears with a selection, so a button is never present unless it can do something.
  • Search and filters are different tools. Search sweeps every visible column; a column filter narrows one. The summary counts them separately.
  • A bulk action runs on what it can. Select ten with one contactless account and Enrich still runs on nine, then reports 1 skipped — no contacts. Disabling the button because one row is ineligible would make you deselect rows to hunt for the offender.
  • Ineligible row actions are greyed with the reason, not hidden — a missing item reads as a feature that does not exist.
  • Row actions are pinned right and cannot be hidden. One click to open, one for everything else — the same verbs as the bulk bar, so acting on one row and on twenty reads the same. They stay put while the table scrolls sideways.
  • Remove takes them off this list only. The accounts are kept — a list is a selection, not an owner, and the same company legitimately sits on several. That differs from deleting the whole list, which does remove accounts left on no other list.
